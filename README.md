# AI as a Catalyst Geneva

Static site for AI as a Catalyst Geneva (March 1–3, 2027), built on the MIT Critical Data
"AI as a Catalyst" template used for Copenhagen and Bangkok.

- `index.html`: page content (search for `TODO` and `[VENUE]` for open items)
- `styles.css`, `script.js`: template styles and particle/heading animation
- `assets/`: logos and portraits (`firstname-lastname.jpg`)

Pushing to `main` deploys to GitHub Pages via `.github/workflows/deploy.yml`.
Set **Settings → Pages → Source** to **GitHub Actions** once.
